## 자리를 맞춘 방법

```
배경의 LOST 글자   4.278% x 2.222%   위 (93.405%, 13.413%)  아래 (7.219%, 86.349%)
그림 속 LOST 글자  43.250% x 11.039%  한가운데 (50.125%, 49.242%)
                   ↓ 두 글자 크기의 비가 곧 그림 크기다
그림 크기          9.892% x 20.312%
```

위아래 글자가 **똑같이 4.278% x 2.222%** 로 나와서 양쪽에 같은 크기를 쓴다.

## 새 렌더러를 안 만들었다

배경 렌더러가 이미 **[그림 한 장을 화면 비율 자리에 놓고 창을 따라간다]** 를 한다.
`BoardChromeRenderer` 가 하는 일은 그것을 조각 수만큼 부르고 하나로 묶는 것뿐이다 —
화면이 크기 조절을 한 번만 걸게 하려는 것이다. 조각이 늘 때마다 화면에 줄이 늘면 잊는다.
