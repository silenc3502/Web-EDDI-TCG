# Issue

1. 실행 명령을 안 지우면 화면만 사라진다
    - 증상
        - 확인용 화면 폴더를 지워도 package.json 의 실행 명령은 남는다
        - 그 명령을 치면 webpack 설정 파일이 없다는 오류가 난다
    - 원인
        - 확인용 화면은 폴더와 실행 명령 두 곳에 걸쳐 있다
    - 처리
        - 함께 지웠다. 실행 명령이 50개에서 48개가 되었다
        - **확인용 화면을 지울 때는 실행 명령도 함께 지운다.** 폴더만 지우면 못 띄우는 명령이 남는다

2. src/main 폴더가 통째로 없어졌다
    - 증상
        - MainRenderer 하나를 지웠는데 src/main/ 이 통째로 사라졌다
    - 원인
        - 그 폴더에 그 파일 하나뿐이었다
    - 처리
        - 그대로 두었다. 폴더 이름이 main 인데 사용자가 보는 화면과 무관했다
        - **폴더 이름이 무게를 말해주지 않는다.** main 이라는 이름에 파일 하나가 들어 있었다
