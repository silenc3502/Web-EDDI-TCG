# Issue

1. 확인용 화면 둘이 완전히 같았다
    - 증상
        - add_main_renderer 와 scale_window 가 38줄인데 한 글자도 다르지 않다
        - 이름은 [화면 조립 추가] 와 [창 크기 조절] 이라 다른 것을 확인하는 것처럼 보인다
    - 원인
        - 창 크기 조절을 확인하려고 앞의 것을 통째로 베꼈고, 확인이 끝난 뒤 지우지 않았다
    - 처리
        - 기준에 [확인용 화면끼리 내용이 같으면 하나만 남긴다] 를 넣었다
        - **이름이 다르다고 다른 것을 확인하는 것이 아니다.** 내용을 맞대어 본다

2. 배경이 두 벌인데 살아 있는 쪽이 반대였다
    - 증상
        - src/battle_field/ 의 배경 여섯 파일은 전투 이름이 붙어 있는데 본편이 안 쓴다
        - src/background/ 쪽을 전투 화면과 덱 편성 화면과 확인용 화면 열일곱 개가 쓴다
    - 원인
        - 이름에 battle_field 가 붙어 있어 전투 것으로 보였다
    - 처리
        - 부르는 곳을 따라가 뿌리가 옛 조립뿐인 것을 확인했다
        - **이름에 무엇이 붙어 있는지가 아니라 누가 부르는지로 판단한다**
